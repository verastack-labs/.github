### Claude Code mods

Open-source add-ons for Claude Code, each in its own repo under Apache 2.0.

| Mod | What it does |
| --- | --- |
| [secret-guard](https://github.com/verastack-labs/secret-guard) | Stops API keys, tokens and private keys from being written to disk, put on a command line, or committed to git. |
| [session-meter](https://github.com/verastack-labs/session-meter) | Usage-limit windows, context fullness and session totals in a pane and the status line, with a warning before you hit a limit. |
| [repo-board](https://github.com/verastack-labs/repo-board) | Every repo you own in one pane: uncommitted and unpushed work, commits to pull, and the pull requests that need you. |

Install from a shell, with the mod's name in place of `<mod>` (Claude Code 2.1.295 or newer):

```
claude plugin marketplace add verastack-labs/<mod>
claude plugin install <mod>@<mod>
```

Or, in a terminal Claude Code session: `/plugin install <mod> --marketplace verastack-labs/<mod>`.
